25 kHz Active Bandpass Filter & Peak Detector

Hardware Design | Signal Processing | Op-Amp Circuitry

Hardware Implementation

To successfully isolate a 25 kHz target signal from adjacent 10 kHz and 17 kHz noise, I designed and built an 8th-order cascaded Sallen-Key bandpass filter. The system utilizes an envelope peak detector and an LM339 comparator to trigger a physical indicator when the target frequency is detected.

This video demonstrates the physical circuit successfully illuminating the indicator LED only when the 25 kHz target frequency is applied, fully rejecting the adjacent 10 kHz and 17 kHz signals.

System Design & Simulation

The active filter was constructed using four cascaded 2nd-order stages, designed with a center frequency ($f_0$) of 25 kHz. The theoretical peak gain of 8.34 dB was verified via LTspice simulation (8.69 dB) before physical construction. The steep roll-off creates a massive 27.7 dB separation between the target signal and the 17 kHz noise.
